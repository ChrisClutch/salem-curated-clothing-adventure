A lightweight static app for finding thrift and resale stores around Salem, Oregon.

## Live URL

- Cloudflare Pages: https://salem-thrift-trek.pages.dev/

## Deploy to Cloudflare Pages

1. Push this repository to GitHub.
2. In Cloudflare dashboard, go to **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
3. Select this repository.
4. Build settings:
   - Framework preset: `None`
   - Build command: *(empty)*
   - Build output directory: `/`
5. Set the project name to `salem-thrift-trek`.
6. Deploy.

Cloudflare will publish it as `https://salem-thrift-trek.pages.dev/` if that subdomain is available.
